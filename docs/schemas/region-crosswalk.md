# 地域マスター照合の項目案

[R-14 の岐阜県での検証](../findings/R-14-master-joins.md)に基づく。地域データの照合に使う項目の案。期間は JST の日付で扱う。コードは先頭ゼロを保持する文字列とする。

| 対象 | 保持する項目 | 照合に使う条件 |
|---|---|---|
| 自治体・行政区 | コード体系、5桁地域コード、必要に応じて検査数字付き6桁コード、名称、種別、親地域コード、有効開始・終了日、出典 | 体系・コード・地域種別を照合する。有効終了日はその地域版が適用されなくなる最初の日。6桁の団体コードから5桁に対応付ける場合は検査数字を照合する |
| 廃置分合・行政界変更 | 発効日、変更種別、旧コード・新コードの関係、出典 | コードが継続しても境界の版は変わり得る。分割などでは複数の後継を記録する。履歴上の観測値は観測当時の地域を保持する |
| 行政区域の図形 | データセット識別子、版、基準日、出典 URL、コード、図形、測地系、加工の有無、利用条件 | コード・地域種別と対象時点を照合する。同じコードで図形が複数あれば部品として保持し、必要な場合にまとめる。行政区には親の政令市を記録する |
| 保健所管轄・医療圏 | 提供元、元資料の制度・集計区分・地域ラベル、対応する自治体コード、資料更新日、確認日、有効期間、根拠 | 自治体と別の集計区分として扱う。複数市町村を含む場合は対応を複数行で持つ。管轄の厳密な開始・終了日が不明なら空欄とし、確認した資料の版・対象範囲に限定する |
| 照合結果 | 元のキーと観測期間、候補、結果、理由、根拠、確認日 | 観測期間の途中で変更がある場合は、提供元の集計基準を確認する。データの出典時点と行政区域の基準日は個別に保持する |

結果は「一致」「曖昧」「不一致」「未検証」を使う。

- **一致**はコードと粒度を照合でき、対象期間との整合を根拠で説明できる場合。または公式の管轄表で当該版の対応先を特定できる場合。岐阜市保健所と同市域の対応を記録しても、定点集計の意味は保健所管内の報告のままとする。
- **曖昧**は同名候補、適用時点不明、区域の一対多などで一意に決められない場合。人が根拠を確認するまで地図との結合を保留する。
- **不一致**はコード・検査数字・粒度・時点などの矛盾が判明した場合。元の値を保持し、現在の名称・境界への補完や按分を行わない。
- **未検証**は入力・資料が揃っていない場合。学校キーとの対応は #5・#6・#8 の結果を得てから検証する。

境界の結合状態と感染症データの欠損・未報告・秘匿・明示ゼロは別の項目として扱う。
