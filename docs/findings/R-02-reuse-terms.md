### 文書から確認できたこと

- Tableau の専用規約 S12 は、サービスの一般公開領域に投稿され、投稿者が許諾できるコンテンツについて、サービス利用者にも複製、加工、公開、配布を含む非独占の許諾を与える構成。投稿者はその権限と第三者権利を侵害しないことを保証する。S12 は利用制限の迂回を禁じ、サービスへの負荷やアクセス回数の制限も定めうる。S14 では掲載責任を投稿者に置き、Tableau は掲載データの所有者でも発行者でもないと説明する。
- 対象ビューのフッターは Salesforce サイト規約 S35 にリンクしている。S35 の E 節は投稿者から Salesforce 等への許諾を扱い、G 節は権利者等の許諾または法令上の根拠を求める。S12 の利用者向け許諾と S35 の適用関係・優先関係、当該ビューから書き出される集計に S12 の許諾が及ぶ範囲は未確定。S36 のクロール条項の対象は第三者サイトであり、Tableau Public 自体を定期取得する許諾や一律禁止の根拠には使えない。S41 の商用制限は定義されたデスクトップ製品を対象とし、ブラウザ上の公開サイトへ一律に適用しない。
- S04 第8項は入力された素データを使用者の所有とし、第10項は本会の統計化情報を原則一般開示とする一方、自治体協議による公開単位の変更や制限を設ける。第9・11項の調査研究用使用者への提供と公開条件、第18項の使用者へのファイル提供は、資格や申請を伴う別経路。第12・13項の保管規則はシステム運営側の規則で、外部の保存年限とは区別する。一般閲覧者が外部再配布できる集計・地域・陳腐化時の扱いは、第10項からは確定できなかった。
- S37 はポータルの記事・写真等の営利目的再利用を制限し、条件付きでリンクを認める。外部 Tableau 集計への適用は未確認。S39 は自治体向けの有償個別ビューを案内している。外部事業者に提供できる集計・形式・契約条件は問い合わせ事項。既存の公開ビューについて、一律に個別許諾が必要か不要かは確定していない。
- S03 の非独占利用は学校マスター検索の応答に対応する。API の機能だけを提供するサイトや実質同等の利用、権利侵害、運営妨害、本会が過度・不適切と判断する商用広告等は制限される。表示には最新情報への更新義務があり、掲載中止要請には直ちに従う必要がある。具体的な更新間隔、TTL、履歴保存とスナップショット配布は明示されていない。感染症マップの取得・再利用には適用しない。

### 代表ビューで観測した設定

2026-11-24 13時台 JST にログインせずブラウザで1ビューを閲覧。公式の共有メニューは埋め込みコードを提示し、この観測では旧ローダー `viz_v1.js` を使う形式だった。現行ドキュメント S38 は Public の Embedding API v3 を説明しているが、対象ビューでの v3 初期化は R-03 の確認事項。

同じビュー内のダウンロードメニューに画像、ベクター画像、PDF、PowerPoint が表示された。CSV、クロス集計、データ、ワークブックの選択肢は表示されなかった。公式 FAQ はダウンロード可否を公開者が変更できると説明する。観測はこのビュー・この時点・このメニューに限る。管理者設定、別ビュー、集計 API が実際に返す応答は未確認。出力ファイルや実データは取得していない。

`curl -sS --max-time 15 https://public.tableau.com/robots.txt` の1回の取得は HTTP 200。全ユーザーエージェント向けの `Crawl-delay: 10` と一部経路の除外を確認した。記載はクローラー向けの条件で、データ取得の許諾や許容頻度の保証ではない。収集ワークフローやブラウザ自動化は実行していない。

## 操作別の判断

「未確認」は公開文書と画面だけでは対象用途の許可を確定できない状態。「不可」は本プロジェクトの現行判断で、規約が将来の別経路まで一律に禁止するとの結論ではない。

| 操作 | 判断 | 根拠と実施条件 |
|---|---|---|
| 通常閲覧・公式入口へのリンク | 可能 | S01・S08 の公開表示を確認。外部リンクは S37 第5節の条件に従う |
| 公式埋め込みで表示 | 条件付き | S13・S38 と代表ビューの共有機能。R-03 の手動ローカル表示に限定。公開サイトへの組み込みは別途評価 |
| 公式 API で感染症集計を読む | 未確認 | S09 に集計読取機能はある。対象ビューの利用条件、閲覧者設定と取得可否は別。出力非表示を埋め込み API で迂回する運用を採らない |
| CSV・クロス集計 | 代表ビューでは現状不可 | 確認したメニューに該当項目なし。S10 の公式機能が存在しても、対象ビューで公開者が許可した経路を確認できるまでは試行しない。画像等の公開設定は CSV の根拠にしない |
| 一時キャッシュ | 未確認 | 通常表示に伴うブラウザの内部処理は通常閲覧の範囲。アプリ側キャッシュ、Actions cache、artifact の TTL と破棄条件は要確認 |
| 長期保存・履歴 | 未確認 | S04 の保存規程は運営側に関するもの。対象集計、保持期間、訂正・削除要請、Git 履歴やバックアップからの削除要件を確認 |
| 加工・他データとの結合 | 未確認 | S12 の許諾は肯定材料。対象集計への適用、集計区分・少数値の扱い、出典表示と訂正条件を確認。架空データでの設計は可能 |
| 再公開・CSV/JSON 配布 | 未確認 | S12・S35 の適用関係、S04 の公開範囲、S37 の条件を照合し、集計の権限と表示・ファイル配布の別を確認する |
| 商用利用 | 未確認 | 公開閲覧が無償でも広告・収益化の許可は確定しない。S37 の営利目的制限の適用範囲と Tableau の条件を確認する |
| 定期取得・無人実行 | 未確認 | S12 のアクセス制限、S36・S40、公開者の許可、頻度・時刻・再試行・停止条件の照合が必要。R-16 の判断と承認まで有効化しない |
| 学校情報等検索 API | 条件付き・別系統 | S01・S03。R-08 で利用主体・対象サイト・最小の公式 GET の条件を確認。継続利用前に更新・掲載中止・保存条件を確認 |

## 技術検証で許容する範囲

- R-03 は公式共有機能が提示する代表ビュー1件を手動でローカルに表示する。1セッション・同時実行1とし、`FirstInteractive`、シート名・フィルター名、表示可否だけを確認する。集計行の取得ページ上限は0。公式ドキュメントに沿って v3 の初期化を試す際も同じ公開ビュー・表示目的に限定する。実値・画像の永続化や一般公開はこの試験に含めない。
- 公式共有が使えない、認証要求、拒否、429、CAPTCHA、利用条件の疑義が出た場合は該当操作を止め、発生条件を記録する。非公開経路・元データ・ダウンロード制限回避・負荷試験は採らない。
- R-04 は許可済みの公開集計と経路が明確になるまで、架空データまたは利用許可を確認したサンプルを使う。実データで行う場合は、対象ビュー、列、ページ上限、保存の可否を再確認し、その範囲に限る。R-08 と R-16 は上表の別条件を適用する。

### 日本学校保健会のシステム専用窓口

2026-11-24（JST）、依頼者が日本学校保健会側の窓口に問い合わせを送信したと報告。回答待ち。[S39 p.88 のマップビュー構築・連携窓口](https://www.gakkohoken.jp/files/ivent/20260624/siryo1.pdf#page=88)と[システム専用の問い合わせ案内](https://www.gakkohoken.jp/system_inquiry)を参照。以下は検討時の問い合わせ案。

> 保護者向けに、都道府県・市区町村別の学校閉鎖・出席停止の公開集計を、無料の静的サイトで出典付きで案内することを検討しています。対象は日本学校保健会の公開マップビューの集計に限り、個人情報・施設別の少数値は対象外です。次の項目について、対象範囲と条件をご教示いただけますか。

1. 集計の外部利用に適用される規約、許諾権限を持つ主体、自治体ごとの例外や同意の要否を教えてください。公開ビューへのリンクと公式埋め込み、表示値を取得して別の画面で示す利用を分けてご回答ください。
2. 公式 CSV、集計 API、定期提供ファイルなどの認められた取得経路はありますか。対象の市区町村別ビューにデータ出力の選択肢がない場合、集計の提供や用途限定の許諾を相談できますか。第18項の対象外の利用者向け窓口や個別提供条件があれば教えてください。
3. 日次・週次の無人取得を許容する場合、対象ビュー・列・地域、頻度、時間帯、上限、クライアントの識別、再試行と停止条件を教えてください。
4. 作業用キャッシュや履歴保存、正規化・再集計・他データとの結合、静的サイトでの表示、CSV/JSON の再配布はそれぞれ可能ですか。保存期間、訂正・削除、出典・更新時点の表示、公開粒度・少数値、広告等の商用利用条件も教えてください。
5. 学校検索 API を別途使う場合、更新義務と停止要請を守るための推奨 TTL と更新頻度、障害時の表示停止、スナップショットの保存・公開条件を教えてください。

### Tableau / Salesforce

[S12 の問い合わせ案内](https://www.tableau.com/tos)または[Embedding API の窓口](https://www.tableau.com/developer/tools/embedding-api)に、対象 URL を示して確認する。以下は未送信。

1. S12 の公開コンテンツ条項と、対象ページが案内する S35 の適用関係を教えてください。匿名で閲覧する場合と、公式 Embedding API で処理する場合の追加条件があれば明示してください。
2. ビューのメニューに CSV・データが出ない場合、集計 API の可否を公開者が確認・制御する公式な方法はありますか。公開者の承認が得られた場合に利用できる経路、無人実行・アクセス頻度・キャッシュに関する条件を教えてください。

再配布に必要な根拠が確認できない場合、出典へのリンク案内を候補として残し、取得・静的配信の設計は利用条件を明示した別の情報源で進める。
