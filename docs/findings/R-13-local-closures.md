# R-13　自治体・教育委員会の学級閉鎖情報とオープンデータ

- 対象は [Issue #13](https://github.com/Olein-jp/japan-infection-watch/issues/13)。確認日・完了日 2026-11-24（JST）。
- 岐阜市、神戸市、北九州市のほか、東京都と八王子市を比較した。福岡県は県と市の公表範囲の重複・除外を確認するために参照した。[R-11 の地域比較](R-11-gifu-region.md)に続き、今回は学校等の臨時休業に関する公表資料を対象とした。
- 近況を案内する候補は提供元の公式ページ。北九州市では過去3シーズンの CSV・XLSX が別途公開されており、2019/20年の提供ファイルを確認した。全国・都道府県の週次集計には [R-10 の厚労省資料](R-10-mhlw-absence-pdf.md)を候補とする。市町村の数値を公開する範囲は、対象校、指標、継続性、利用条件が揃った資料から判断する。

## 検証結果と再現手順

1. **閲覧範囲を絞る。** 2026-11-24 15時台（JST）に、各提供元の公式入口、現行の代表資料、利用条件の該当箇所を通常閲覧した。岐阜市は市保健所案内、[9月](https://www.city.gifu.lg.jp/info/kouhou/1001155/1041567/index.html)と[11月の市記者発表](https://www.city.gifu.lg.jp/info/kouhou/1001155/1042430/index.html)、[県・市の共用カタログ](https://gifu-opendata.pref.gifu.lg.jp/dataset/?q=%E5%AD%A6%E7%B4%9A%E9%96%89%E9%8E%96)を確認した。カタログの「学級閉鎖」検索は17件で、学校基本調査等が表示され、閉鎖の配布データは見つからなかった。県の学校情報リンクの転送先はメンテナンス中と表示した。
2. **配布リンクと集計の脚注を照合する。** 北九州市の現行ページ「1 1週間分の施設数・人数の集計結果」から[第46週 PDF](https://www.city.kitakyushu.lg.jp/files/001239461.pdf)を1件開く。2026-11-19付、第46週（11月9〜15日）、p.1。HTTP 200 の応答を一時領域で開き、Poppler 26.05.0 の `pdftotext -layout` と p.1 の描画で照合した。本文の13施設は、週次表の閉鎖種別の合計（休校0、学年閉鎖4、学級閉鎖9）および施設種別の合計（1＋5＋3＋4）と一致した。累計表の下の注記は、同一週・同一施設で複数の措置があった場合に休校、学年閉鎖、学級閉鎖の順に優先し1件とする。週次一覧では第39週の PDF リンクが見当たらず、公式のゼロとして扱う根拠は得られなかった。[岐阜県の報告 p.8](https://www.pref.gifu.lg.jp/uploaded/attachment/478328.pdf#page=8)も同じ手順で表5を照合し、閉鎖実施校数の括弧内は全学校数に占める割合と確認した。
3. **機械判読可能な資料を探す。** 「学級閉鎖」で[神戸市カタログ](https://catalog.city.kobe.lg.jp/dataset?q=%E5%AD%A6%E7%B4%9A%E9%96%89%E9%8E%96)を検索し、該当0件を確認した。北九州市カタログの[検索結果](https://data.bodik.jp/organization/401005?q=%E5%AD%A6%E7%B4%9A%E9%96%89%E9%8E%96)は2件で、閉鎖に該当したのは過去シーズンのデータセット1件。規約とリソース表示を読み、2019/20年の CSV 1件を配布ページのリンクから `curl -fLsS --max-time 15` で開いた（HTTP 200）。Python 3 の標準 `csv.reader` で表頭12列を確認。後続の243物理行は行数のみを確認した。施設名や個別行を出力・保存せず、現行 HTML の個票数値とも照合していない。
4. **県の公表範囲を確認する。** [福岡県の2026/27年シーズン案内](https://www.pref.fukuoka.lg.jp/contents/seasonal-flu-alert-2026-2027.html)は、県の資料から北九州市・福岡市・久留米市を除外すると明記。都道府県の行政区域と県発表の対象区域は両方を記録する。全国の共通資料には別掲区分があるため、その範囲は [R-10](R-10-mhlw-absence-pdf.md)に従う。

## 全国展開の段階と欠測の扱い

| 段階 | 採用条件と提供候補 | 地域の欠測 |
|---|---|---|
| 1．全国・都道府県の基準 | 厚労省・JIHS の学校欠席者数週報を候補とし、都道府県・別掲市・全国計を公表値の単位で表示する。施設数、欠席者数、当週、累計を保持。公開条件は R-16 で判定 | 個別自治体の値が得られない場合は公表粒度で表示。市の公式リンクが見つかれば対象範囲と確認日を付けて案内 |
| 2．条件の揃う自治体から追加 | 公式な提供元と資料、対象校・参加範囲、疾患・措置、指標と集計期間、更新・訂正方法、個別の利用条件を確認する。現在の週次集計と過去の履歴を、それぞれ利用可能な期間で扱う | 公表対象外、未公表・未報告、提供元が明記したゼロ、更新停止・取得失敗、表示制限を区別。理由が分からない空欄や掲載のない週は「未確認」 |
| 3．自治体を拡張 | 都道府県単位で候補の有無・確認日・提供元を記録し、条件を満たした自治体の地域数と対象範囲を表示する。施設の重複、地域境界、疾患・集計定義の異なる値を検証してから比較可能な範囲を広げる | 公開済みの自治体数と全自治体数を区別する。収録率が不明な値に市全体を代表する割合を付けない。停止中の案内は確認日を示す |

北九州市の週次施設数、神戸市教育委員会の発表別閉鎖学級数、八王子市の延べ学級数は別の指標として保持する。個別報告では決定・報告日、開始日、終了日、更新時点を区別する。延長が掲載されない資料から確認日現在の閉鎖状況は確定できない。インフルエンザ、インフルエンザ様疾患、複数疾患が一括された公表表の区別も必要。

R-14 には公表地域・設置者・学校種別の照合、R-15 には期間・単位・欠測と版管理、R-16 にはカタログと現行資料の適用範囲、取得・保存・加工・再公開・商用利用の条件を引き継ぐ。R-18 では、各地域で実際に公開できる粒度と公式リンクで補う範囲を評価する。

## 受入基準の照合

- 岐阜市、神戸市、北九州市と補足候補について、形式、対象、閉鎖期間、疾患、更新、利用条件を比較した。確認日、代表資料の該当箇所、取得できない範囲を記録した。
- 全国市区町村を一度に網羅する前提は置かず、共通の集計、条件の揃う自治体、対象範囲を明示した拡張の順で評価した。確認は代表資料と過去 CSV 1件に限定した。
