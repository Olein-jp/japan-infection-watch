# R-12　47都道府県の感染症情報源と地域粒度

- 対象は [Issue #12](https://github.com/Olein-jp/japan-infection-watch/issues/12)。確認日・完了日 2026-11-24（JST）。
- [R-11 の岐阜県・岐阜市調査](R-11-gifu-region.md)で使った確認項目を、47都道府県の感染症発生動向の公表資料に適用した。
- 47都道府県の公式入口を特定し、すべての行に根拠と確認範囲を記録した。全国・都道府県の共通比較は [R-09 の JIHS 週次定点 CSV](R-09-jihs-csv.md)を候補とし、県より細かい公表単位は各提供元の定義を使う。[JIHS 第46週速報](https://id-info.jihs.go.jp/surveillance/idwr/provisional/2026/46/index.html)

## 確認方法と表の見方

1. [東京都健康安全研究センターの地方感染症情報センター一覧](https://idsc.tmiph.metro.tokyo.lg.jp/klink/)（2026-11-12更新）で公表主体と入口を特定し、公式の週報、配布案内、地図、サイト利用条件に進んだ。コードは[総務省の全国地方公共団体コード](https://www.soumu.go.jp/denshijiti/code.html)の都道府県部分（先頭2桁）を使用した。保健所管内への対応付けは R-14 で扱う。
2. 2026年第46週（11月9〜15日）を主な見本とし、入口・表のタイトルと地域区分、指標の単位、発行日または更新案内を確認した。「週」「月報」等は掲載対象または発行周期。曜日・時刻を確認できた場合は併記した。掲載される疾患・指標・周期は定点種別や表により変わる。
3. 「文書」は公式の案内・画面・配布リンク、「原表」は資料の表頭・列・脚注、「実行」は公開配布ファイルの内容まで確認したことを示す。「限定」は一部の経路や表を確認できた状態。PDF のページ番号はファイル先頭を p.1 とする。
4. 市町村欄では、市町村として別掲された例、自治体名を冠する保健所、未確認を区別した。「保健所名」は表での扱いを示す。自治体境界と一致する場合は根拠が得られた範囲で明記した。「未確認」は当該資料で確認できなかった範囲を示し、資料の不存在は判断していない。
5. 「一般制限」等はリンク先の著作権・サイト利用案内で確認した内容。著作権表示、例外、出典表示、個別規約の優先は各リンク先を参照する。サイト本体とセンター・外部配布先で適用範囲が異なり得るため、個別データの保存・再公開・商用利用・定期取得の判断は R-16 に引き継ぐ。

## 判断と残課題

- 全国比較の共通範囲は JIHS の全国・都道府県別とする。地域詳細は、保健所、医療圏、地区、別掲市ごとに元の集計単位・分母・対象疾患・速報時点を保持する。保健所の所在地や表示名から市町村別の値は推定しない。愛媛の週報では定点報告の保健所区分が患者住所を示すものではないと明記されている。[愛媛県週報 p.3](https://www.pref.ehime.jp/uploaded/attachment/194767.pdf#page=3)
- R-14 では基準日時点の保健所管轄と自治体コードを照合する。R-15 では定点種別、指標・分母、報告の対象地域、集計時点と訂正を扱う。R-16 では優先候補の配布ファイルとサイト規約の適用範囲、定期取得・保存・再公開の条件を確認する。R-18 では公開可能な粒度と地域を、条件が確認できた情報源から判断する。
- 受入基準に対応し、47都道府県（コード01〜47、重複なし）の行に、公式入口、公開形式、地域粒度、更新、利用条件、検証状態・根拠を記載した。確認できなかった範囲は各行に残した。全件取得処理・定期収集・自治体個別の閉鎖情報調査は対象外。
