## 形式・データ辞書

2026-11-24 14:20 JST に curl 8.7.1 で公式 CSV の GET に成功。Python 3.13.5 の標準ライブラリで厳密デコードし、両週とも Shift_JIS と CP932 で読み取れた。UTF-8 ではデコードエラー。発行元の文字コード指定は確認できていないため、PoC では両週を読み取れた Shift_JIS を使う。各ファイルは39列、表題・メタデータ・2段の見出し4行と、全国の「総数」・47都道府県48行、末尾の空行1行。先頭列は地域、残りは19疾患の2列組。[実行手順と出力](../../poc/jihs/README.md)

| 項目 | 原表と出力の扱い |
|---|---|
| 対象週 | CSV 内の報告年・週番号と期間を採用。PoC は ISO 週から得た月曜〜日曜を原表の月日と突き合わせ、両週が一致。年またぎの扱いは[公式2026年報告週対応表](https://id-info.jihs.go.jp/surveillance/idwr/calendar/2026/index.html)を参照し、追加年の検証時にも照合する |
| 地域 | 「総数」を全国、名称で照合した47地域を都道府県として保持。地理コードは R-14/R-15 で扱う |
| 疾患 | インフルエンザ、ＲＳウイルス感染症、咽頭結膜熱、Ａ群溶血性レンサ球菌咽頭炎、感染性胃腸炎、水痘、手足口病、伝染性紅斑、突発性発しん、ヘルパンギーナ、流行性耳下腺炎、急性出血性結膜炎、流行性角結膜炎、細菌性髄膜炎、無菌性髄膜炎、マイコプラズマ肺炎、クラミジア肺炎、感染性胃腸炎（ロタウイルス）、COVID-19 |
| 報告・定当 | 当該週の報告数（件、整数）と定点当たり報告数（件/定点、小数第2位までの文字列）を並べて保持。分母となる定点数の列はなく、丸め済みの値からの逆算や地域間での合算は行わない。全国値は掲載された「総数」を使う |
| ハイフン・空欄 | 数値欄で `-` を両週で観測。原表にはこの表のハイフンの内訳を区別する情報がなく、`dash` として保持。数値欄の空欄は未観測だが `blank` として別に扱う。第45週の全国の急性出血性結膜炎は報告3・定当0.00で、表示上の0.00とハイフンを区別できる |

第45週の速報 CSV と、11月20日発行の[同週 IDWR PDF](https://id-info.jihs.go.jp/surveillance/idwr/idwr/2026/idwr2026-45.pdf) pp.32–34 を照合した。PDF を描画して表・列見出し・脚注と ARI の分離を確認し、macOS PDFKit で抽出した地域名と2指標の文字列を、疾患列の順序を対応させて比較した。例として CSV の末尾の `COVID-19` は PDF p.32 の2番目の疾患に対応する。全国と47都道府県 × 19疾患 × 2指標の1,824セルは、ハイフンも含めて差分0。第46週の PDF は調査時点で未刊行。[週報一覧](https://id-info.jihs.go.jp/surveillance/idwr/idwr/2026/index.html)の発行予定は11月30日。

PoC には一時領域で作った検証用入力を渡し、空欄・ハイフン・数値ゼロを区別できることを確認した。地域の重複・欠落、指標列の入れ替わり、週番号と期間・URL の不一致、タイムゾーンのない取得日時、ファイル不在、不正な文字列の8件はいずれも終了コード2で停止した。

## 速報と訂正

対象週ページの「更新」と第45週 PDF p.37 に、速報値は後日の週報・年報で修正され得ること、週報上で訂正を行うことが示されている。[週報の訂正告知](https://id-info.jihs.go.jp/niid/ja/allarticles/surveillance/4755-teisei-owabi.html)では本文の訂正、[年報の訂正一覧](https://id-info.jihs.go.jp/surveillance/idwr/annual/correction/index.html)では、たとえば2026-11-02更新欄に集計表の表示修正を確認した。今回比較できた第45週には数値差も表記差もなく、同一週の速報 CSV が差し替わった前後の実物は未確認。訂正の告知経路が常に同じかどうかも未確認。

R-15/R-16 では、報告年・週と資料区分、原本 URL・作成日・取得時刻・ハッシュで版を識別する。比較対象は同じ週・疾患・地域・指標に揃え、訂正版の根拠と値の差分を紐付ける。更新日だけで版を上書きせず、取得失敗時は最後に検証できた版を保持する方針を評価する。速報と週報の一致は確定を意味しないため、速報の区分を表示に引き継ぐ。

## 利用条件

[JIHS 感染症情報提供サイト利用規約](https://id-info.jihs.go.jp/usage-contract.html)の冒頭は、各項の条件に従う複製・公衆送信・翻案・商用利用を認める。1項は出典と加工の明示、2項は第三者権利、5項は予告なしの変更と免責、7項イ・ウは個別転載注記の遵守と無断改変の制限を定める。8項記載の制定日は2014-08-25。第45・46週の配布ページに CSV 固有の再利用注記は確認されなかった。第45週の週報 PDF p.37 には、学術研究・公衆衛生活動に関わる業務以外での無断転載を禁じる個別注記がある。

- **閲覧・試験取得・一時保存・正規化**。公式リンクから2週分を取得し、配布ファイルを変更せず、出典付きの JSON をローカル検証用に生成した。PDF は照合に使用した。
- **再公開・商用利用・長期保存**。一般規約の許容条件は確認済み。R-16 で対象 CSV の個別条件と第三者権利、1項と7項の適用、出典と加工表示、保持方針を評価する。週報 PDF の再配布には個別注記を適用する。
- **定期取得**。取得頻度や自動取得条件の明記は確認できなかった。R-16 で公開経路、負荷を抑えた運用と訂正の追跡方法を検討する。
