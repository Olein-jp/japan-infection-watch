## 岐阜の対応表と履歴

- 9市町の名称とコードが一致した。各務原市と岐南町は各2地物。自治体コードと地理データは一対多になり得る。各図形を保持し、同じコードで集約する際に範囲が欠けないようにする。
- **曖昧の例**。県の週報の「岐阜」は、保健所別と医療圏別で範囲が違う。表・集計区分を読み取れる場合に、8市町または岐阜市を含む9市町へ対応付ける。定点報告値は集計区分を維持し、個別自治体への割り振りに使わない。[R-11 の所管確認](R-11-gifu-region.md#保健所管轄と行政区域)
- **不一致の例**。旧柳津町 `21304`（団体コード `213047`）は2006-01-01に岐阜市へ編入され、今回の N03 に該当地物は0件。岐阜市のコードは編入前後で継続する。2005年の値は当時の地域・範囲を保持し、現行市域へ結合するには再集計の根拠が必要。[e-Stat の廃置分合](https://www.e-stat.go.jp/municipalities/cities/absorption-separation-of-municipalities/21201)・[J-LIS 改正一覧](https://www.j-lis.go.jp/data/open/cnt/3/2757/1/20230720.pdf)
- **行政区の例**。浜松市は2024-01-01に7区から3区へ再編した。旧北区の三方原地区は中央区、それ以外は浜名区に移った。旧北区を新しい1区に対応付けたり、旧区の数値を地区別に推定したりできる根拠はない。浜松市は履歴の文書確認。境界ファイルの変換は岐阜市で行った。[浜松市 行政区再編](https://www.city.hamamatsu.shizuoka.jp/kikaku/kuseido/)

## GeoJSON 変換の実行確認

2026-11-24 15:30 JST 頃、[岐阜県 ZIP](https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2026/N03-20260101_21_GML.zip) を取得した。HTTP 200、3,272,831バイト、SHA-256 は `5ffebfff62a97d17c14911f6b0d6aff8ccc76e4b5f95184ff73d540529eb5ad1`。ZIP 内のシェープファイルは48地物。付属する GeoJSON は明示的な EPSG:6668 を持ち、岐阜市の形状は1面を含む MultiPolygon だった。

シェープファイルから `21201` を選び、JGD2011（EPSG:6668）から WGS 84（EPSG:4326）へ変換した。RFC 7946 に沿って座標は経度・緯度の順、外環は反時計回り、出力に `crs` メンバーは置かない。PROJ が選んだ変換の公称精度は1 m。付属 GeoJSON も同じ変換を行って比較し、属性と座標（許容差 `1e-8` 度）が一致した。この許容差は同梱2形式の比較に用いた値。[RFC 7946 §3.1・§4](https://www.rfc-editor.org/rfc/rfc7946.html)

出力は有効な Polygon 1地物。範囲は西136.678678、南35.351284、東136.886272、北35.543102。測地線による面積は203.604 km²で、市公表の203.60 km²と小数第2位で一致した。これは大きさの確認に使った。[岐阜市の面積](https://www.city.gifu.lg.jp/info/syoukai/1006141/1006142.html)

同じ原典で再実行した結果はバイト単位で一致した。入力の座標系を EPSG:4326 に差し替えた場合、原典ファイルが欠落した場合、比較用の市町村名を架空の名称に変更した場合、出力先が既に存在する場合は、いずれも終了コード2で停止し、出力を変更しなかった。

実行環境は Python 3.13.5、Fiona 1.10.1（GDAL 3.9.2）、pyproj 3.7.2（PROJ 9.5.1）、Shapely 2.1.2（GEOS 3.13.1）。リポジトリルートから実行する。

```sh
(
  set -eu
  scratch=$(mktemp -d)
  python3 -m venv "$scratch/venv"
  "$scratch/venv/bin/python" -m pip install -r poc/local-government/requirements-boundary.txt
  curl -fLsS --max-time 22 --max-filesize 6000000 -w 'HTTP %{http_code}\n' \
    'https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2026/N03-20260101_21_GML.zip' \
    -o "$scratch/gifu.zip"
  shasum -a 256 "$scratch/gifu.zip"
  unzip -q "$scratch/gifu.zip" -d "$scratch/source"
  "$scratch/venv/bin/python" poc/local-government/verify_gifu_boundary.py \
    "$scratch/source" "$scratch/gifu-city-2026.geojson"
  printf '%s\n' "$scratch/gifu-city-2026.geojson"
)
```

岐阜県版の素材・出力は一時ディレクトリで扱った。N03 2026年版は CC BY 4.0 の表示があり、出力には版・原典 URL・ライセンス・加工の有無を記録した。公開時の出典には元資料名、URL、加工の明示を含める。原典の測量法に基づく複製承認番号 `R 7JHf 351` と、予定している公開・再配布に関する手続の要否は R-16 で確認する。[N03 の許諾条件](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html)・[国交省の利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement.html)・[国土地理院の手続案内](https://www.gsi.go.jp/LAW/2930-index.html)
