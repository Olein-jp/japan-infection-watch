# 調査結果

`R-01-xxx.md` のように調査 ID を含むファイル名で保存する。

```markdown
# R-xx 調査名
- GitHub Issue: #番号
- 調査日: YYYY-MM-DD JST
- 状態: 未着手 / 進行中 / 検証済み / ブロック / 完了
- 結論: 取得可能 / 条件付き / 取得不可 / 未確認

## 調査目的・対象外
## 一次情報（URL・資料名・改訂日・確認日・該当箇所）
## 文書上確認できた事実
## 実行環境・再現手順
## 実測結果（件数・列・エラー・検証ログ）
## データ構造・粒度・単位・分母
## 利用条件・保存・再公開の判定
## 制約・未確認事項
## サービス設計への影響・代替案
## 受入基準のチェック
## 次に対応すべきIssue
```
