- 結論 岐阜県の週報・Excel から県計と岐阜市保健所管内を含む8保健所の週次インフルエンザ定点データが確認できる。基幹定点の週報は5医療圏。任意の市町村の値は保健所集計から割り振れない。岐阜市の独自統計は年度の届出数を確認した。

## 保健所管轄と行政区域

[県の所管市町村表](https://www.pref.gifu.lg.jp/uploaded/image/12596.jpg)および[報告用アカウント申請の施設所在地一覧](https://www.pref.gifu.lg.jp/page/246729.html)で、岐阜市と県の岐阜保健所の管轄を確認した。ここでの対応は現行資料に基づく。過去の境界・運用変更は未検証。

| 元資料の地域名・列群 | 解釈 |
|---|---|
| 県全体・岐阜県計 | 県の集計。第46週の県インフルエンザ報告数は8保健所の合計と一致 |
| 岐阜市（保健所別） | 岐阜市保健所。所管市町村は岐阜市のみ。地理的に市域と一致するが、数値の対象は同管内の定点報告で、全住民や全医療機関の数ではない |
| 岐阜（保健所別） | 県の岐阜保健所。羽島市、各務原市、山県市、瑞穂市、本巣市、岐南町、笠松町、北方町の8市町 |
| 岐阜（医療圏別） | 岐阜圏域。所管表の岐阜行は岐阜市保健所と県の岐阜保健所を含む。基幹定点の週報で使う地域粒度 |
| その他の保健所・医療圏 | 8保健所の内訳は岐阜市、岐阜、西濃、関、可茂、東濃、恵那、飛騨。5圏域は岐阜、西濃、中濃（関・可茂）、東濃（東濃・恵那）、飛騨 |

地域の識別は提供元と集計区分と原ラベルを使い、同じ「岐阜」を名前だけで結合しない。定点当たり報告数は率なので地域間で加算しない。岐阜市列から市民の居住地別発生数を推定しない。ほかの市町村への割り振り、県・国・市をまたいだ単純加算は行わない。

- 県インフルエンザは第44〜46週の県計＋8保健所で定点当たり報告数27セルが PDF と Excel で一致した。3週とも報告数の8保健所合算は県計と一致。第46週は p.6 の ARI 定点数を分母として全9列を再計算し、小数第2位で一致した。例として第46週は県計358件／45定点＝7.96、岐阜市51件／9定点＝5.67、岐阜保健所55件／9定点＝6.11。
- Excel の第47〜53週は週番号・日付だけがあり、指標欄は空欄だった。歴史部分には `…` があり、PDF には `-` 表記も見える。未集計・未報告・定点なし・対象外等を資料と指標に即して確認し、空欄や記号からゼロを作らない。データ・グラフ編 p.5 下段のクラミジア肺炎表は先頭部分の「医療圏別／岐阜」表記が重複して見える。その列の意味は確定せず、試験対象から外した。
- PoC は想定する表見出しと地理区分を照合する。情報編 PDF の誤指定、市統計書 Excel の誤指定、ファイル不在の各ケースが終了コード2で停止することを確認した。照合用の率を変更した場合と、後続週の空欄を与えた場合も検証で停止した。

## 利用条件と引き継ぎ

- **県週報・Excel**。県公式サイトはリンクを原則可とし、著作権法上認められる場合を除く無断複製・転用を制限。今回は少数の公開資料を通常閲覧し、一時領域で照合した。対象 PDF・Excel へのオープンライセンス表示、長期保存・再公開・商用利用・定期取得の個別条件は確認できず、公開用途の採用は保留。県カタログ規約の原則 CC BY 4.0 はカタログに適用し、旧 COVID-19 CSV のデータセットには別の表示がある。[県サイトの著作権](https://www.pref.gifu.lg.jp/page/79328.html) · [県カタログ規約](https://www.pref.gifu.lg.jp/page/75247.html)
- **市資料**。市サイトの一般条件は無断複製・転用を制限。令和7年版市統計書は PDL1.0 と市独自の重要情報に従い、出典・加工の明示と第三者権利の確認が必要。市衛生年報の案内は出典明記による引用を認め、商用目的を禁止。年度届出数を週次の代替に使う根拠はない。[市サイトの著作権](https://www.city.gifu.lg.jp/info/kouhou/1008373/site/1011572.html) · [市統計書の利用条件](https://www.city.gifu.lg.jp/info/toukei/1008686/1038653/1038654.html) · [市衛生年報の利用条件](https://www.city.gifu.lg.jp/info/toukei/1009046/1009047/1009048.html)
- R-12 は資料ごとに県計・保健所・医療圏・市町村、対象制度、期間、形式、取得条件を確認する。R-14 は管轄と自治体コードの対応を有効時点つきで扱う。R-13 は学校閉鎖資料を独立に調査し、R-16 は公開リンクと継続取得・保存・再公開の条件を扱う。市町村の公式値が得られない場合は、値のある管轄単位での案内と公式資料へのリンクを候補とする。
