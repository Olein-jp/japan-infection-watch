# 調査方針

[AGENTS.md](../AGENTS.md)の作業手順と完了条件を適用する。調査結果は [findings](findings/README.md) に保存し、情報源、結論、適用範囲を [一次情報台帳](source-register.md) と [判断記録](decisions.md) に反映する。

## 根拠と暫定判断

台帳の URL は出発点として扱う。移転時は公式サイトから後継を探し、旧 URL、置換先、確認日を残す。根拠ごとに「文書確認」「実行確認」「仮説」「未確認」「検証不能」を記す。API の仕様と対象公開ビューでの動作を別々に評価する。日本学校保健会の学校検索 API の用途と、Tableau 上の感染症・閉鎖の公開集計はそれぞれ確認する。

調査前の見通しは[初期指示書](../CODEX_INITIAL_PROMPT.md)の第3節に記載されている。ビューの公開範囲、閉鎖指標の変更、参加範囲、取得可能期間、各提供元の粒度は仮説として出発し、該当 Issue で確かめる。

規約については適用主体、発効日、条項、公開者の権利、ビュー設定を記録する。通常閲覧、公式 API、CSV、キャッシュ、長期保存、加工、再公開、商用利用、定期取得を個別に「可能」「条件付き」「不可」「未確認」で整理する。判断が不明な場合は通常閲覧と公式機能の最小試験に限定し、必要な問い合わせを起案する。送信には承認が必要。

## PoC と記録

対象とアクセス上限を決め、原則として公開集計の少量サンプルから始める。認証・ダウンロード制限・アクセス制限を回避せず、拒否、429、CAPTCHA 時は停止する。実行環境、バージョン、日時、URL、コマンド、HTTP 状態、取得件数、照合箇所、エラーを記録し、証跡から認証情報を除く。紙面や画面との照合は該当ページ、見出し、脚注、集計単位を含める。

データ辞書では地域粒度、対象施設、期間、指標、単位、分母、版と更新日時を明示する。欠損の状態と明示的なゼロ、出席停止人数と一般の感染症報告数、保健所管轄と市町村境界を区別する。参加範囲が不明な集計を地域全体へ外挿せず、秘匿値や閉鎖種別の逆算をしない。テストの原則は架空データとする。取得結果のローカル保存は保存条件を確認した公開集計に限る。

PoC の技術は目的に応じて Node.js/TypeScript、Playwright、Python などを比較する。採用した版、ロックファイル、セットアップ手順を記録する。初期構築では実行環境の候補と配置先を文書化する。
