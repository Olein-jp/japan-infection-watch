# 実現可能性評価

2026-11-24（JST）時点の [R-18 の評価](../findings/R-18-feasibility.md)。公開・開発の判定は依頼者の承認前の案。

| 判断する事項 | 評価 |
|---|---|
| 初期版の対象 | JIHS の全国・47都道府県の週次定点集計が第一候補。利用できる疾患・週から開始し、履歴は直近1年を上限候補にする。厚労省の学校休業集計は、条件が揃えば報告区分を保った別系列で追加する。 |
| 月0円での運用 | GitHub Free の標準アドレスと標準 Actions runner を使う。架空の都道府県週次1年分は JSON と索引で約49.5 MB。公開一式500 MB・月間帯域50 GB・デプロイ5分を管理の目安とし、保管枠を別途確認する。全市区町村の日次1年分は現行形式で約3.65 GBの JSON を要する試算で、初期版の対象外。 |
| 自治体・学校別 | 自治体の数値は公表単位・指標・許諾が揃った地域から追加候補にする。確認した公式情報へのリンクを代替にできる。学校別表示は見送り、日本学校保健会の回答と少数集計の扱いを確認してから再評価する。 |
| Go／No-Go 案 | R-19 での仕様検討は条件付き Go。開発は依頼者の Go 判断後に進む。実データ公開・定期取得は現時点で No-Go。資料別の利用条件、データ品質、復旧、運営費の確認と承認が必要。 |

次の R-19 では、採用資料と代替表示を切り替えられる仕様、変更時のみ公開する手順、無料枠の判定、更新失敗時の旧版維持を具体化する。GitHub Pages を利用できない場合の無料代替は [R-18 の成立条件](../findings/R-18-feasibility.md#月0円での成立条件)に記載した。
