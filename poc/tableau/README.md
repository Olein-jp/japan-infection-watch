# Tableau 公開ビューの表示確認

R-03 の検証ページ。Tableau Public の公式 Embedding API v3 で、日本学校保健会の市区町村別学級閉鎖地図を1件表示し、シート名とフィルター名を確認する。

## 実行方法

Python 3 が使える環境で、リポジトリのルートから起動する。ライブラリは Tableau Public が配信する公式モジュールをブラウザから読み込む。

```sh
python3 -m http.server 8030 --bind 127.0.0.1 --directory poc/tableau
```

1. ブラウザで <http://127.0.0.1:8030/> を開く。
2. 「市区町村別の学級閉鎖地図を表示」を1回押す。
3. 地図と「FirstInteractive を受信」の表示を確認し、「シート名とフィルター名」を開く。
4. 確認後はタブを閉じ、サーバーを `Ctrl+C` で止める。

1ページにつき手動起動1回。同時実行は1とし、集計行の取得ページ上限は0。失敗または60秒で停止し、自動で再試行しない。認証要求・拒否・429・CAPTCHA が表示されたら操作を止め、原因を記録する。

実行結果と出典は [R-03 の報告書](../../docs/findings/R-03-tableau-embedding.md)、検証条件は [R-02](../../docs/findings/R-02-reuse-terms.md#技術検証で許容する範囲)を参照。

## R-04 公式サンプルの集計と CSV 出力

上と同じローカルサーバーを起動し、<http://127.0.0.1:8030/summary.html> を開く。

1. 「公式サンプルを表示」を1回押す。対象は Tableau の公式出力例 `Superstore_embedded_800x800/Overview`。
2. `Total Sales` を選び、「集計の先頭1ページを取得」を押す。総行数、ページ数、列名と型、最大2行を確認する。
3. 表示条件を変えず、画面の `Quantity` と `Average Discount` を API 結果と比較する。
4. 「同じシートを公式 CSV で出力」を1回押す。出力 API 完了後、ブラウザのダウンロードで保存ファイルを開き、指標名と値を突合する。

CSV 出力は取得時の集計総行数が1〜12行の場合に有効になる。認証要求や拒否、出力制限があれば操作を止める。確認後はタブとローカルサーバーを閉じる。検証結果と未確認事項は [R-04 の報告書](../../docs/findings/R-04-tableau-summary.md)を参照。
